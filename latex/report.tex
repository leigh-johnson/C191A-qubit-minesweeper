\begin{abstract}

    Erasure based quantum error correction is a promising development in the quest to create a functional quantum computer. Converting some fraction of Pauli errors to erasure errors can lead to significant increases in code distance and error rate thresholds in surface code encoded logical qubits. Furthermore, methods for erasure conversion have been demonstrated on most leading quantum computing platforms including transmon, neutral atom, and trapped ion hardware. In this project we investigate how erasure-aware decoding alters the noise threshold of the rotated surface code by comparing the MWPM and MWPF decoders using single qubit  circuit-level Monte Carlo simulations in Stim. We evaluate two regimes: pure Pauli noise $(R_e = 0)$ and full erasure-dominant noise $(R_e = 1)$. Under Pauli noise, both decoders achieve thresholds near $0.6\%$. Under erasure noise, MWPF reaches a threshold of $3.0\%$, while MWPM with reweighting reaches only about $1\%$. This confirms that explicitly leveraging erasure locations through MWPF's hypergraph formulation provides a substantial advantage and supports continued development of quantum hardware that converts physical faults into detectable erasures.

    %     We implemented Minimum Weight Parity Factoring and Minimum Weight Perfect Matching decoders for the erasure aware surface code and the surface code respectively and we conducted a monte carlo simulation where we repeatedly sampled from a noisy quantum circuit run on a single logical qubit. From that data we determined error thresholds for both the erasure converting surface code and the standard surface code, and found our own estimation of the lift achieved by implementing erasure conversion in a simulated quantum circuit.

\section{Introduction}
\label{sec:intro}

Fault-tolerant quantum computation requires the correction of physical faults at rates below a code-dependent threshold. In the surface code, this threshold depends not only on the magnitude of the underlying noise but also on the information available about the location and type of each fault \cite{fowler_surface_2012}\cite{acharya_quantum_2025}\cite{bluvstein_logical_2024}. Several hardware platforms now permit the detection of leakage events, atom loss, or other mechanisms that remove population from the computational subspace, including superconducting circuits with erasure qubits and neutral-atom architectures with mid-circuit imaging and leakage-to-erasure conversion \cite{kubica_erasure_2023}\cite{wu_erasure_2022}\cite{ma_high-fidelity_2023}\cite{scholl_erasure_2023}\cite{chow_circuit-based_2024}\cite{reichardt_fault-tolerant_2025}. Such events can be modeled as erasures, and their positions can be supplied directly to the decoder \cite{gu_fault-tolerant_2025} \cite{gu_optimizing_2024}\cite{sahay_high-threshold_2023}\cite{chadwick_erasure_2025}.

In this study, we examine the effect of such erasure information on the rotated surface code. We perform circuit-level Monte Carlo simulations of memory experiments using Stim~\cite{gidney_stim_2021} and consider two limiting noise regimes: depolarizing Pauli errors and full erasure conversion. We compare two decoders. Minimum-Weight Perfect Matching (MWPM), as implemented in PyMatching~\cite{oscarhiggott_oscarhiggottpymatching_2025,higgott_sparse_2025}, interprets all faults as Pauli errors. Minimum-Weight Parity Factor (MWPF) solves a hypergraph parity-factor problem that incorporates erasure locations explicitly and is implemented in the Hyperion software~\cite{wu_yuewuomwpf_2025,wu_minimum-weight_2025}.

The simulations show that both decoders achieve thresholds near $0.6\%$ under depolarizing noise, while in the erasure-dominant regime MWPM reaches approximately $1\%$ and MWPF achieves about $3\%$. These results give a quantitative reference for the expected performance of the rotated surface code under idealized erasure conversion and allow a direct assessment of the benefit provided by decoders that make use of erasure information, in line with recent proposals for erasure-based fault-tolerant architectures~\cite{kubica_erasure_2023,gu_fault-tolerant_2025,sahay_high-threshold_2023,chadwick_erasure_2025}.

The following sections review the relevant noise models, decoder architectures, and prior work that motivate our experimental design.
\section{Background \& Related Work}

\subsection{Noise Models}
\paragraphsc{Pauli Noise.}
Quantum processors experience several classes of errors. A common simplification is to model all physical noise as independent Pauli errors, sampled uniformly from $\set{X,Y,Z}$. For the surface code this is often instantiated as a depolarizing channel \cite{fowler_surface_2012,pesah_interactive_2023}:
\begin{align}E_{\text{pauli}}(\rho) & = (1-p)\rho + \dfrac{p}{3}(X\rho X + Y\rho Y + Z\rho Z) & \quad \text{[Depolarizing error channel]}
\end{align}

Pauli noise has become the standard baseline for evaluating code performance and thresholds in both early and recent large-scale experiments \cite{fowler_surface_2012}\cite{acharya_quantum_2025}.


\paragraphsc{Leakage.}
However, this model does not capture important features of real devices. A particularly harmful type of hardware noise is leakage, where population escapes the computational subspace into higher energy levels (e.g.,$\ket{2}$ in a weakly anharmonic oscillator) and can persist across many QEC cycles, producing spatially and temporally correlated errors \cite{suchara_leakage_2014}\cite{wilen_correlated_2021}\cite{miao_overcoming_nodate}\cite{yang_coupler-assisted_2024}. To mitigate this, many proposals and recent experiments introduce leakage-reduction units (LRUs) or related mechanisms that periodically detect and reset leaked qubits \cite{suchara_leakage_2014}. See \nameref{appendix:leakage} for a more detailed description.


\begin{align}E_{\text{erase}}(\rho_j) & = (1-p_{\text{erase}})\rho_j + p_{\text{erase}}\ket{e}\bra{e} & \quad \text{[Erasure error channel \cite{suchara_leakage_2014}]}
\end{align}

Unlike unknown Pauli errors, the location of an erasure is known to the decoder. This structural information dramatically changes the performance of error-correcting codes and has been formalized in recent work on erasure qubits and erasure-based architectures \cite{kubica_erasure_2022} \cite{gu_fault-tolerant_2025} \cite{gu_optimizing_2024}.

For a distance $d$ error-correcting code, up to $\dfrac{d-1}{2}$ arbitrary Pauli errors but up to $d-1$ erasures, because the decoder knows which qubits are affected. \cite{kubica_erasure_2023} \cite{gu_fault-tolerant_2025}.

This asymmetry leads to substantially higher thresholds and more favorable scaling in the erasure-dominated regime. Circuit-level simulations and code-capacity analyses of the surface code and related architectures consistently find erasure thresholds far above those for depolarizing noise—on the order of tens of percent for tailored codes—compared to ~1\% at the circuit level. \cite{wu_erasure_2022} \cite{sahay_high-threshold_2023} \cite{gu_optimizing_2024}.

The erasure paradigm is not purely theoretical. In neutral-atom hardware, metastable Yb qubits, Rydberg entangling gates, and fast, state-selective imaging enable mid-circuit conversion of dominant errors into detectable erasures \cite{wu_erasure_2022}\cite{ma_high-fidelity_2023}\cite{scholl_erasure_2023} \cite{chow_circuit-based_2024}
\cite{norcia_midcircuit_2023}\cite{reichardt_fault-tolerant_2025}. Similar ideas are being pursued in superconducting circuits via dual-rail encodings and tailored measurement schemes \cite{kubica_erasure_2023} \cite{gu_fault-tolerant_2025} \cite{gu_optimizing_2024}, and in hybrid architectures that strategically deploy erasure qubits to trade physical cost for logical performance \cite{chadwick_erasure_2025} \cite{baranes_leveraging_2025}. These works collectively motivate studying how erasure-aware decoders perform on the surface code under idealized Pauli vs. erasure noise models, as we do here.

At the same time, erasure detection is imperfect and requires additional physical operations. Extra erasure checks may introduce correlated errors or additional decoherence, and realistic erasure-conversion schemes rarely achieve 100\% conversion efficiency \cite{ma_high-fidelity_2023}\cite{wu_erasure_2022}\cite{gu_optimizing_2024}. This motivates separating "pure Pauli" and "pure erasure" regimes in simulations as a first step, which we adopt in this project.

\subsection{Erasure Qubits}

An erasure qubit is engineered so the dominant source of errors is from erasures. A bias towards erasure-type errors occurs natively in some types of qubits (e.g. photons) or can be engineered by converting leakage errors to erasures (e.g. with LDUs in superconducting qubits). For more information on how erasure conversion works for neutral atoms, refer to the following papers: \cite{wu_erasure_2022} \cite{baranes_leveraging_2025} \cite{scholl_erasure_2023} .For superconducting qubits, refer to the following papers: \cite{gu_optimizing_2024} \cite{gu_fault-tolerant_2025}.

\subsection{Surface Code}\label{subsec:surface-code}

The \emph{surface code} is a leading candidate for fault-tolerant quantum computation due to its local stabilizers, high threshold, and compatibility with two-dimensional hardware architectures~\cite{fowler_surface_2012}\cite{pesah_interactive_2023}. In its rotated layout, a single logical qubit is encoded across a $d \times d$ lattice of physical qubits, with repeated stabilizer measurements producing a space--time syndrome history. The code distance $d$ sets the minimum number of physical errors required to implement a logical error.

If the physical error rate $p$ is below a threshold $p_{\mathrm{thr}}$, the logical error rate $P_L$ decreases approximately exponentially with $d$:
\begin{align}
    P_L \propto \left( \frac{p}{p_{\mathrm{thr}}} \right)^{(d+1)/2} \quad \text{{Logical error rate}}
\end{align}
a scaling extensively validated in both simulations and experiments~\cite{fowler_surface_2012,fowler_optimal_2013,acharya_quantum_2025,bluvstein_logical_2024}. This exponential suppression underpins scalable, fault-tolerant architectures. Recent work has begun to explore how accumulated erasures, atom loss, and code deformations affect surface-code thresholds in neutral-atom settings, motivating specialized schemes for handling ongoing erasure processes \cite{kobayashi_erasure-tolerance_2025,reichardt_fault-tolerant_2025,li_fast_2025}.

Because erasure errors are easier to correct and reveal additional information to the decoder (example: \autoref{fig:surface-code-erasure-comparison}), the erasure-aware threshold can be substantially higher than the threshold under Pauli noise, especially when decoders are explicitly optimized for erasure structure~\cite{sahay_high-threshold_2023,gu_fault-tolerant_2025,gu_optimizing_2024}. Quantifying this gap for practical decoders is one of the main goals of our study.




\paragraphsc{Circuit-level Noise Thresholds.}
If physical qubit error is below a critical noise threshold, the logical error rate should be suppressed exponentially as the number of physical qubits per logical qubit is increased. In the surface code, the approximate relation between $d$ code distance corresponding to $2d^2 - 1$ physical qubits per logical qubit, the physical error rate $p$, logical error rate $E_d$, and error rate threshold $p_{thr}$  \cite{acharya_quantum_2025}.

\subsection{Decoding: MWPM vs.\ MWPF}
\label{subsec:decoding}

\textbf{MWPM decoders} (e.g., PyMatching) cast the decoding problem as a \emph{graph matching} task: syndrome defects are nodes, edges represent possible error events, and a minimum-weight perfect matching yields the most likely Pauli error configuration consistent with the observed syndrome~\cite{oscarhiggott_oscarhiggottpymatching_2025}\cite{higgott_sparse_2025,gidney_answer_2023-1}. This approach has become the de facto standard for decoding the surface code under uncorrelated Pauli noise~\cite{fowler_surface_2012}\cite{fowler_optimal_2013}. Our baseline simulations follow this tradition, using Stim and MWPM-based decoders to estimate thresholds under depolarizing noise \cite{gidney_stim_2021}.

However, the standard MWPM formulation assumes:
\begin{itemize}
    \item errors are well-approximated as \textbf{independent Pauli errors}, and
    \item the decoder has no side information about \emph{where} errors occurred.
\end{itemize}

In particular, MWPM does not naturally exploit the additional structure provided by erasure events, where locations of faults are known but their Pauli type is not. Extensions exist that partially incorporate erasure information within a matching framework, particularly for erasure qubits \cite{kubica_erasure_2023}\cite{gu_fault-tolerant_2025}, but these remain limited compared to full hypergraph methods.


In the MWPF framework, decoding becomes a \emph{minimum-weight parity factor} problem: find a set of hyperedges whose parities match the observed syndrome while minimizing the total weight derived from the noise model~\cite{wu_minimum-weight_2025}. Hypergraph matching is NP-hard in general, but the HyperBlossom implementation used in this work employs primal--dual relaxations, clustering, and sparse data structures to achieve near-linear average runtime scaling on surface codes and other LDPC codes at relevant code distances~\cite{wu_minimum-weight_2025}.

By construction, MWPF can incorporate erasure locations directly into the decoding graph, rather than approximating them as effective Pauli errors. This is especially powerful in architectures that deliberately convert dominant noise channels to erasures~\cite{wu_erasure_2022,kubica_erasure_2023,gu_fault-tolerant_2025,chadwick_erasure_2025}. Our experiments leverage this capability by comparing MWPF and MWPM in regimes where erasures are either absent (pure Pauli noise) or dominant (pure erasure noise).

\subsection{Motivation for Our Experiments}
\label{subsec:motivation}

The literature sketched above suggests a coherent picture:

\begin{enumerate}
    \item Real hardware produces Pauli errors, leakage, and loss;
          \textbf{leakage-reduction and mid-circuit detection convert a large fraction of these into erasures}
          in both neutral-atom and superconducting platforms%
          \cite{wu_erasure_2022,ma_high-fidelity_2023,scholl_erasure_2023,
              chow_circuit-based_2024,kubica_erasure_2023,gu_fault-tolerant_2025}.

    \item \textbf{Erasures are significantly easier to correct} than unknown Pauli errors and can
          dramatically improve thresholds and overhead when properly exploited%
          \cite{sahay_high-threshold_2023,gu_optimizing_2024,baranes_leveraging_2025,
              chadwick_erasure_2025}.

    \item The \textbf{surface code threshold} depends strongly on the decoder’s ability
          to use erasure information, as seen in simulations and early fault-tolerant experiments%
          \cite{fowler_surface_2012,acharya_quantum_2025,bluvstein_logical_2024,
              reichardt_fault-tolerant_2025,kobayashi_erasure-tolerance_2025}.

    \item \textbf{MWPF} explicitly incorporates erasure locations and correlated error mechanisms
          through a hypergraph formulation, while \textbf{MWPM} is tuned for uncorrelated Pauli noise%
          \cite{oscarhiggott_oscarhiggottpymatching_2025,higgott_sparse_2025,
              wu_minimum-weight_2025}.
\end{enumerate}

These observations motivate our study: by comparing MWPM and MWPF on the rotated surface code under both Pauli-only and erasure-dominant noise, we aim to quantify how erasure-aware decoding reshapes the threshold landscape and to clarify systematic deviations between ``idealized'' literature thresholds and practical simulation results obtained with Stim- and MWPF-based workflows. In this work, we simulate rotated-surface-code memory circuits under depolarizing and erasure noise using Stim. We compare MWPM and MWPF decoders across distances $d \in \set{3, 5, 7, 9, 11}$, with Monte Carlo sampling to estimate logical error rates and extract threshold behavior. This allows us to quantify how erasure-aware decoding scales the fault-tolerant physical error threshold, compared to a model limited to only Pauli noise.

\section{Methods \& Results}\label{sec:results}
\subsection{Overview}\label{sec:results-overview}

We studied the performance of a rotated surface code under various noise and error syndrome decoding regimes (\autoref{tab:1}), with the goal of observing the impact of erasure conversion on our definition of the fault-tolerant error threshold $p_{thr}$. This section summarizes the simulation setting, noise regimes, and decoding methods used throughout our experiments. More detailed procedures are provided in sections \nameref{sec:experiment1} through \nameref{sec:experiment4}.

\paragraphsc{Circuit Stabilizer Simulations}
We simulate the rotated surface code circuit with Stim \cite{gidney_stim_2021}. For each code distance $d \in \{3,5,7,9,11\}$, we run circuit-level Monte Carlo sampling using Sinter, collecting logical measurement outcomes after $d$ rounds of stabilizer measurements. The logical observable is the $X$ operator of the encoded qubit, initialized in the state $\ket{+}$. We define a binary success indicator to be $1$ if we measure $\ket{+}$ after $d$ rounds (otherwise the shot results in a logical failure), from which we estimate the logical error rate:
\begin{align}P_L = \dfrac{\text{k}}{\text{n}} \quad \text{$k=$ number of logical failures, $n$ = total number of shots}
\end{align}

For each circuit and decoding method described in \autoref{tab:1}, we plot $P_L$ vs physical error rate $p$ in \autoref{fig:pymathing-pthresh}, \autoref{fig:mwpf-pthresh}, \autoref{fig:mwpf-pthresh-erase}, \autoref{fig:pymatching-pthresh-erase} and fit a binomial distribution with \verb|sinter|. \footnote{See: Craig Gidney's answer to StackExchange question: `max\_shots and max\_errors to reduce uncerainty in threshold
    curves with sinter / stim?' for a detailed explanation of the method we used to combine per-shot and per-round distributions. We use per-shot representation in our final results. \cite{gidney_answer_2023}}

\paragraphsc{Noise Regimes.}
We study two noise models, parameterized by a physical qubit error rate $p$ and an erasure-conversion ratio $R_e$. The noise channel is applied to each data qubit after one and two-qubit Clifford gate operations, and to each ancilla qubit before a round of stabilizer syndrome measurements.

\begin{itemize}
    \item \textbf{Pauli noise (depolarizing channel)} ($R_e = 0$): We sample uniformly at random with probability $1-p$ of no error occurring and probability $p/3$ of any error in $\set{X, Y, Z}$ occuring.
    \item \textbf{Erasure-dominant channel} ($R_e = 1$): A \verb|HERALDED_ERASE| event occurs with probability $p$ per qubit, providing the decoder with the exact location of the affected qubit. The qubit is reset to a maximally mixed state before the next round of syndrome measurements.
\end{itemize}
Intermediate values of $R_e$ are not considered in this work; we focus on the two external cases needed to quantify the benefit of erasure information.

\paragraphsc{Syndrome Decoders}
We evaluate two four combinations of noise model and decoding strategy:
\begin{enumerate}
    \item \textbf{MWPM (PyMatching), Pauli noise}: standard minimum-weight perfect matching baseline.
    \item \textbf{MWPM with per-shot reweighing, erasure noise}: min-weight perfect matching, with edge weights conditioned on whether an erasure event occurred.
    \item \textbf{MWPF, Pauli noise}: an ablation showing MWPF performance without erasures.
    \item \textbf{MWPF, erasure noise}: frames the problem of decoding syndrome measurements
          and erasure error locations as a hypergraph matching problem.

\end{enumerate}

\paragraphsc{Threshold Definition.}
We define the threshold $p_{\mathrm{thr}}$ as the crossing point where higher code distances achieve lower logical error rates. In the figures, we visualize this by identifying the crossing of the $d=7$ and $d=9$ curves; crossings of $d=3,5$ and $d=9,11$ provide lower and upper bounds. All threshold estimates shown in Table~\ref{tab:1} and Figures~\ref{fig:best-threshold-comparison}--\ref{fig:thresholds} follow this criterion.

\paragraphsc{Summary of Experiments.}
Table~\ref{tab:1} lists the parameter ranges, decoder configurations, and measured thresholds for all four experiments. The highest threshold observed is $p_{\mathrm{thr}}\approx 3.0\%$ under full erasure conversion with the MWPF decoder, compared to $\approx 0.6\%$ for all methods under Pauli noise. These values demonstrate the qualitative and quantitative advantage of erasure-aware decoding on the rotated surface code.

\subsection{Fault Tolerant Code Distance}

The X-intercept of the fit line represents the minimum code distance $d$ needed for one logical bit to survive approximately one trillion rounds, a representative target for running long quantum algorithms.

For $R_e = 1.0$ and erasure-aware hypergraph MWPF decoding, \autoref{fig:fault-tolerant-projection} shows that a logical qubit implemented with $d \approx 17$ (or $2d^2 \approx 578$ physical qubits in the array) is projected to survive one trillion rounds. This result should be interpreted cautiously because we do not calculate residuals from the least-squares fit to quantify goodness of fit. The hypergraph MWPF dataset is extrapolated from a more limited range of code distances (green, $d<9$) compared to other noise regimes. Due to the computational expense of the hypergraph decoder, we could not sample as much below-threshold data in that particular noise regime; see \nameref{sec:memleak-sidequest}.

\subsubsection{Experiment 1: Minimum-Weight Perfect Matching Baseline}\label{sec:experiment1}

\textbf{Data:}
\href{https://github.com/leigh-johnson/C191A-qubit-minesweeper/tree/main/datasets/circuit%3Dsurface_code%3Arotated_memory_x/decoder%3Dpymatching}{GitHub link}.\\
\textbf{Results:} \autoref{fig:pymathing-pthresh}.

\paragraphsc{Setup.}
We study a purely depolarizing Pauli-noise regime with $R_e = 0$, using the rotated surface-code memory circuit and decoding with minimum-weight perfect matching (PyMatching). This experiment provides a standard MWPM baseline for comparison with MWPF and erasure-aware schemes.

\paragraphsc{Procedure.}
For each $(d,p)$, we compile the Stim circuit into a detector error model (DEM), convert it into a Tanner-graph representation with log-likelihood edge weights, and construct a \texttt{pymatching.Matching} object. During Monte Carlo sampling, each noisy shot produces a syndrome vector, which is decoded by PyMatching's Sparse Blossom algorithm to obtain a Pauli correction before measuring the logical observable. A shot is counted as a logical failure when the corrected logical measurement disagrees with the ideal value. Full details of the MWPM decoding pipeline (DEM, parity-check matrix, and optimization problem) are given in \autoref{appendix:mwpm-details}.

\subsubsection{Experiment 2: Minimum-Weight Parity Factor Baseline}\label{sec:experiment2}

\textbf{Data:}
\href{https://github.com/leigh-johnson/C191A-qubit-minesweeper/tree/main/datasets/circuit%3Dsurface_code%3Arotated_memory_x/decoder%3Dmwpf/erasure%3D0.0/solver%3DSolverSerialJointSingleHair}{GitHub link}.\\
\textbf{Results:} \autoref{fig:mwpf-pthresh}.

\paragraphsc{Setup.}
This experiment repeats the Pauli-only noise regime ($R_e = 0$) but replaces MWPM with the minimum-weight parity factor (MWPF) decoder. The circuit, noise model, and sampling parameters are otherwise identical to Experiment~\ref{sec:experiment1}. We use the \texttt{mwpf[stim]@0.2.12} implementation with the \texttt{SolverSerialJointSingleHair} solver and clustering parameter \texttt{cluster\_node\_limit = 50}.

\paragraphsc{Procedure.}
For each $(d,p)$, we construct a Stim DEM and pass the circuit to \texttt{SinterMWPFDecoder}, which builds a hypergraph detector error model with error mechanisms represented as hyperedges. During Monte Carlo sampling, each shot’s syndrome is decoded by solving a minimum-weight parity-factor problem on this hypergraph, yielding a correction operator that is applied before measuring the logical observable.
In the Pauli-only regime the hypergraph is mostly graph-like and MWPF approximates MWPM. A detailed description of the MWPF hypergraph construction and decoding problem is given in \autoref{appendix:mwpf-details}.

\subsubsection{Experiment 3: Erasure-Aware Minimum-Weight Parity Factor}\label{sec:experiment3}

\textbf{Data:}
\href{https://github.com/leigh-johnson/C191A-qubit-minesweeper/tree/main/datasets/circuit%3Dsurface_code%3Arotated_memory_x/decoder%3Dmwpf/erasure%3D1.0/solver%3DSolverSerialJointSingleHair}{GitHub link}.\\
\textbf{Results:} \autoref{fig:mwpf-pthresh-erase}.

\paragraphsc{Setup.}
Experiment~\ref{sec:experiment3} repeats the MWPF decoding of Experiment~\ref{sec:experiment2}, but switches from pure Pauli noise to a fully erasure-dominant regime with $R_e = 1.0$. All circuit-level Pauli noise channels are replaced by \texttt{HERALDED\_ERASE} channels, giving the decoder explicit access to erasure locations. This setting approximates an idealized version of the erasure-conversion protocols proposed in erasure-qubit architectures~\cite{wu_erasure_2022}.

\paragraphsc{Procedure.}
For each $(d,p)$, we use \texttt{SinterMWPFDecoder} to build a hypergraph DEM that includes both syndrome detectors and erasure-tagged error mechanisms. Each shot yields a syndrome along with implicit information about which error mechanisms correspond to heralded erasures; MWPF then solves the minimum-weight parity-factor problem on this erasure-aware hypergraph and maps the resulting parity factor to a Pauli correction. As in the other experiments, we classify each shot as a logical success or failure based on the corrected logical measurement.

Due to the memory footprint of the hypergraph representation, the number of shots per task is smaller, leading to broader confidence intervals in the threshold fit. See \autoref{sec:memleak-sidequest} for profiling details. Additional decoding details for the erasure-aware MWPF case are given in \autoref{appendix:mwpf-details}.

\subsubsection{Experiment 4: Erasure-Aware Minimum-Weight Perfect Matching}\label{sec:experiment4}

\textbf{Data:}
\href{https://github.com/leigh-johnson/C191A-qubit-minesweeper/tree/main/datasets/circuit%3Dsurface_code%3Arotated_memory_x/decoder%3DHeraldedEraseDecoder/erasure%3D1.0}{GitHub link}.\\
\textbf{Results:} \autoref{fig:pymatching-pthresh-erase}.

\paragraphsc{Setup.}
This experiment adapts the MWPM baseline of \autoref{sec:experiment1} to the fully erasure-converted regime ($R_e = 1.0$), following the two-step strategy of \citeauthor{gu_fault-tolerant_2025}. First, a Stim circuit with \texttt{HERALDED\_ERASE} channels produces both a syndrome bitstring and an erasure bitstring. Second, we decode the syndrome using PyMatching on a fixed DEM graph, but with per-shot edge reweighting conditioned on the observed erasure pattern.

\paragraphsc{Procedure.}
We convert the rotated-memory circuit so that each physical fault is modeled as a \texttt{HERALDED\_ERASE} followed by one or more dedicated \texttt{DETECTOR} instructions acting as erasure checks. From this circuit we build a DEM and extract two disjoint detector sets: standard syndrome detectors and herald detectors associated with erasure checks. Base log-likelihood edge weights are assigned from the DEM error probabilities, and per-herald weight shifts are precomputed for the edges touched by each herald. For each shot, we read the herald bitstring, update the edge weights according to which heralds fired, and run PyMatching once with this reweighted graph to obtain a correction. This implements a simple correlation-aware decoding rule without changing the underlying MWPM graph structure. The full per-shot reweighting formulas and DEM analysis appear in Appendix~\ref{appendix:heralded-mwpm-details}.

\section{Discussion}\label{sec:discussion}
\paragraph{Key Findings}
We found that an erasure aware version of the surface code using a MWPF decoder, under the assumption that 100\% of Pauli errors can be converted to erasure errors, has a threshold, $p_{th}$, between 2.75\% and 3.0\%. This is roughly 4x the threshold we measured for a surface code encoded logical qubit using the standard MWPM decoder and assuming 0.0\% erasure conversion.

\paragraphsc{Reduced tolerance of errors in our surface code simulations}
\autoref{tab:1}

In the case where depolarizing noise is modeled with purely Pauli errors, we reference the physical error threshold $p_{thr}$ published by \citeauthor{wu_erasure_2022} ($p_{thr} = 0.937(4)\%$) and \citeauthor{acharya_quantum_2025} ($p_{thr} \approx 1\%$) \cite{wu_erasure_2022}\cite{acharya_quantum_2025}.

In Experiment1, we visually estimated a much \textit{lower} error ($p_{thr} = 0.775$, \%err $=22.5\%$) for our X-rotated surface code with pure Pauli noise and the PyMatching decoder. We ruled out decoder implementation as a contributing factor (under this particular noise regime) after determining a similar result in our ablation study of MWPF in Experiment2 ($p_{thr} = 0.750$, \%err $=25.0\%$). We attribute this systemic error to multiple sources, in order of significance:

\begin{itemize}
    \item \autoref{fig:stim-circuit-gen}. We intended to assume perfect stabilizer measurements, but our circuit implementation applied the depolarizing error channel to each data qubit per measurement round.
    \item We applied the depolarizing noise channel to one and two-qubit gates at the same rate. Our references consider only two-qubit gates.
\end{itemize}

    \centering
    \hspace{-4.8em}
    \includegraphics[width=0.9\linewidth, height=\textheight, keepaspectratio ]{fig_stim_circuit_implementation.png}
    \caption{ \textbf{Stim circuit implementation used in our baseline simulations.} A depolarizing channel was unintentionally applied during stabilizer measurement rounds, reducing the effective threshold. This implementation detail explains the discrepancy between our measured Pauli thresholds and those reported in the literature. }
    \label{fig:stim-circuit-gen}
\end{figure}

For the next/subsequent experiments, we recommend writing out \href{https://github.com/quantumlib/Stim/blob/main/doc/file_format_stim_circuit.md}{.stim circuit files} that can be inspected and versioned. Depending on the experiment procedure demands, it may be useful to extend or customize Stim's circuit generator in our own codebase.

\paragraphsc{High Uncertainty in MWPF Experiments}
In our MWPF experiments, our Monte Carlo simulation was limited to 10,000 - 50,000 shots at a time (vs. 500,000 per single run in other trials). We aggregate the datasets from many (5+) in order to compare against other experiments. Fewer samples resulted in a wider confidence interval for MWPF samples, especially at low physical error rates (see \autoref{fig:mwpf-pthresh} and \autoref{fig:mwpf-pthresh-erase}). We attempted to gather enough data to make a fair comparison between our visual estimations for $p_{thr}$, especially for the sampling region around the threshold. However, the binomial fit method in our $P_L$ vs. $p$ plots is very sensitive to outlying datapoints. A visual estimate at the extreme of the very wide confidence interval for $d=7,9,11$ in \autoref{fig:mwpf-pthresh-erase} puts the $p_{thr}$ region anywhere from $\approx 3-6$\%. We report the most conservative value in our results table.

\paragraphsc{Erasure Conversion Reduces Overhead}
Hardware design is ultimately constrained by the number of physical qubits required to achieve a target logical error rate. The code-distance extrapolation \autoref{fig:fault-tolerant-projection} shows a significant reduction in surface code distance needed to survive one trillion rounds (roughly the number of rounds needed to run a useful computation).

Under depolarizing noise with standard MWPM decoding, reaching $P_L \approx 10^{-12}$ at $p=0.01$ would require code distances on the order of $d \approx 100$, corresponding to $\sim 2d^2 \approx 2 \times 10^4$ physical data qubits per logical qubit. Incorporating erasure information but retaining a graph-based decoder (MWPM with per-shot reweighting) reduces this requirement to $d \approx 60$ (a few thousand physical qubits), whereas full erasure conversion combined with MWPF decoding further lowers the estimate to $d \approx 17$ (hundreds of physical qubits).

\paragraph{Implications for Future Quantum Computers}

While additional work is required to address the discrepancies between our results and the results present in other papers on erasure based quantum error correction, they still show a significant improvement for erasure conversion over standard surface code implementations. Based on our projections for the logical error rate as a function of code distance, for a system with a pauli error rate p = 1\%, a distance 14 erasure converting surface code would achieve a logical error rate of $10^{-10}$, which is the error rate necessary for most quantum computing applications. Depolarization rates below this threshold have already been demonstrated for neutral atoms, trapped ions, and transmon qubits. \cite{Muniz_High_Fidelity_Universal_Gates_2025} \cite{L\"{o}schnauer_Scalable_High_Fidelity_All-electronic_Control_2024} \cite{Li_Realization_of_High_Fidelity_CZ_Gate_2024} \cite{Thorbeck_High-fidelity_gates_in_a_transmon_2024}


\paragraph{Future Work}
Although our extrapolations rely on linear fits over a limited range of $d$ and on idealized noise models, they illustrate that a $\sim 5\times$ improvement in threshold from erasure-aware hypergraph decoding translates into at order-of-magnitude reduction in code-distance overhead. We predict decoders that exploit erasure locations will be an essential part of any fault-tolerant quantum computer system. Indeed, \citeauthor{bluvstein_architectural_2025} \citeauthor{baranes_leveraging_2025} both make considerable investments into various erasure-aware decoding schemes in their work on fault-tolerant neutral atom architectures.


\subsection{Future Work}
\paragraphsc{Imperfect Detection}
\citeauthor{wu_erasure_2022} describe an error taxonomy in Yb-137 with four distinct leakage errors in a detectable subspace and one in an undetectable subspace in order to conclude 98\% of errors that occur in Yb-137 can theoretically be treated as erasures in the XZZX surface code. We are curious about the quantitative rates for missed Yb+ ions, missed ground-state atoms, and would want to compare a model for effective vs. idealized erasure conversion.

\paragraph{Correlated Errors}
Many of the simulations and studies we found were limited to independent error mechanisms, but erasure-aware decoding requires a conditional error structure. \citeauthor{scholl_erasure_2023} highlight that erasure conversion enables ``exploring the effect of errors on experimental outcomes at a microscopic level and studying correlations between different error sources'' by conditioning on preparation and decay erasures recorded during the same shot \cite{scholl_erasure_2023}. Our circuit-level simulations treat Pauli and erasure events as independent, but real hardware exhibits spatial and temporal structure that influences decoder performance.

We're excited by a recent pull request to Stim introduces a \texttt{pymatching-correlated} decoder interface (\href{https://github.com/quantumlib/Stim/pull/1012}{PR~\#1012}), which will enable Sinter to pass correlation-aware detector models directly into PyMatching. We tried to implement this feature ourselves (see \autoref{sec:experiment4}), but our erasure-aware results were only slightly improved compared to the Pauli noise regime. We're excited to see an official reference implementation and look forward to figuring out where we went off the rails.


\section{Conclusion}

We quantified the effect of erasure information on the threshold of the rotated surface code. Under depolarizing noise, both MWPM and MWPF produce thresholds near $0.6\%$. Under full erasure conversion, MWPF reaches approximately $3\%$, while MWPM with reweighting reaches roughly $1\%$. The lower Pauli thresholds in our data are explained by an unintended measurement-noise channel in the Stim circuits (\autoref{fig:stim-circuit-gen}). The results show that decoders using explicit erasure locations provide a clear operational advantage for quantum error correction. Further work will evaluate correlated error models with the new correlation-aware PyMatching interface when it becomes available \cite{oscarhiggott_oscarhiggottpymatching_2025}.

\section{Appendix: A Fun Sidequest: Profiling a Memory Leak}\label{sec:memleak-sidequest}

\subsection{Minimum-Weight Perfect Matching (MWPM)}
\label{appendix:mwpm-details}

For the MWPM-based experiments (Experiments~\ref{sec:experiment1} and~\ref{sec:experiment4}), decoding is based on the detector error model (DEM) representation used by Stim~\cite{gidney_stim_2021}.

\subsubsection*{Detector Error Model and Parity-Check Matrix}

For a fixed circuit, the DEM defines a set of binary detectors $\{D_i\}_{i=1}^m$ and error mechanisms $\{E_j\}_{j=1}^n$. Each error mechanism $E_j$ is annotated with the subset of detectors it flips, giving a binary parity-check matrix%
\footnote{This matrix can be viewed as the parity-check matrix of a Tanner graph, as in classical LDPC codes~\cite{noauthor_tanner_2025}.}
\begin{align}
    H \in \{0,1\}^{m\times n}, \qquad
    H_{ij} =
    \begin{cases}
        1, & \text{if error mechanism } E_j \text{ flips detector } D_i, \\[4pt]
        0, & \text{otherwise}.
    \end{cases}
\end{align}
Each column of $H$ has Hamming weight 1 or 2, so the DEM induces a graph where error mechanisms correspond to edges or half-edges between detector nodes.

\subsubsection*{Edge Weights}

Each mechanism $E_j$ has an associated error probability $p_j$ determined by the circuit-level noise model. We assign a log-likelihood edge weight~\cite{higgott_sparse_2025}
\begin{align}
    w_j \approx \log\!\left(\frac{1 - p_j}{p_j}\right).
\end{align}
The pair $(H, \{w_j\})$ defines the MWPM decoding graph used by \texttt{pymatching.Matching}~\cite{oscarhiggott_oscarhiggottpymatching_2025}.

\subsubsection*{Decoding Problem}

Each noisy shot produces a binary syndrome vector $\mathbf{s} \in \{0,1\}^m$, where $s_i$ is the outcome of detector $D_i$. Let $\mathbf{x} \in \{0,1\}^n$ indicate which error mechanisms occurred. The syndrome and error vector satisfy
\begin{align}
    H \mathbf{x} = \mathbf{s} \pmod{2}.
\end{align}
PyMatching's Sparse Blossom algorithm solves the minimum-weight decoding problem
\begin{align}
    \hat{\mathbf{x}}
    =
    \arg\min_{\mathbf{x} \in \{0,1\}^n}
    \left\{
    \sum_{j=1}^n w_j x_j
    \;:\;
    H \mathbf{x} = \mathbf{s} \pmod{2}
    \right\},
\end{align}
and maps $\hat{\mathbf{x}}$ to a Pauli correction on the data qubits. Comparing the corrected logical observable to its ideal value determines whether the shot contributes to $P_L$. For an intuitive explanation of how MWPM infers logical operators from the matching, see Gidney's StackExchange post~\cite{gidney_answer_2023-1}.

\subsection{Minimum-Weight Parity Factor (MWPF)}
\label{appendix:mwpf-details}

For the MWPF-based experiments (Experiments~\ref{sec:experiment2} and~\ref{sec:experiment3}), we use the \texttt{mwpf[stim]} hypergraph decoder~\cite{wu_yuewuomwpf_2025,wu_minimum-weight_2025}.

\subsubsection*{Hypergraph Detector Error Model}

As in the MWPM case, a Stim DEM specifies detectors $\{D_i\}_{i=1}^m$ and error mechanisms $\{E_j\}_{j=1}^n$. MWPF generalizes the graph structure by allowing each error mechanism $E_j$ to flip an arbitrary subset of detectors, interpreted as a hyperedge $F_j \subseteq \{D_1,\dots,D_m\}$. This yields a hypergraph incidence (parity-check) matrix
\begin{align}
    H^{(\mathrm{hyp})} \in \{0,1\}^{m\times n}, \qquad
    H^{(\mathrm{hyp})}_{ij} =
    \begin{cases}
        1, & \text{if detector } D_i \text{ is incident on hyperedge } F_j, \\[4pt]
        0, & \text{otherwise}.
    \end{cases}
\end{align}
Columns of $H^{(\mathrm{hyp})}$ may have Hamming weight larger than two, corresponding to multi-detector error events or erasure constraints.

\subsubsection*{Edge Weights}

Each error mechanism $E_j$ has probability $p_j$ under the circuit-level noise model. MWPF uses the same log-likelihood weighting,
\begin{align}
    w_j \approx \log\!\left(\frac{1 - p_j}{p_j}\right),
\end{align}
which is passed into the HyperBlossom solver~\cite{wu_minimum-weight_2025}.

\subsubsection*{Parity-Factor Decoding}

Each shot produces a syndrome vector $\mathbf{s} \in \{0,1\}^m$. Let $\mathbf{x} \in \{0,1\}^n$ be the vector indicating which hyperedges are included in the parity factor. The detector constraints are
\begin{align}
    H^{(\mathrm{hyp})} \mathbf{x} = \mathbf{s} \pmod{2}.
\end{align}
MWPF solves the minimum-weight parity-factor problem
\begin{align}
    \hat{\mathbf{x}}
    =
    \arg\min_{\mathbf{x} \in \{0,1\}^n}
    \left\{
    \sum_{j=1}^n w_j x_j
    \;:\;
    H^{(\mathrm{hyp})} \mathbf{x}
    =
    \mathbf{s}
    \pmod{2}
    \right\},
\end{align}
and maps $\hat{\mathbf{x}}$ to a Pauli correction on the data qubits. In the pure Pauli regime ($R_e = 0$), most columns of $H^{(\mathrm{hyp})}$ remain graphlike (Hamming weight $\leq 2$), so MWPF effectively reduces to a generalized matching decoder. When $R_e = 1$, heralded erasures produce additional hyperedges that connect multiple detectors and encode erasure constraints directly into the decoding problem.

\subsection{Heralded-Erasure Reweighting for MWPM}
\label{appendix:heralded-mwpm-details}

Experiment~\ref{sec:experiment4} implements a two-step, correlation-aware MWPM strategy following Gu \emph{et al.}~\cite{gu_fault-tolerant_2025}. The key idea is to reuse a single DEM graph but adjust edge weights on a per-shot basis according to which heralded erasures are observed.

\subsubsection*{Syndrome vs.\ Herald Detectors}

After converting the circuit to use \texttt{HERALDED\_ERASE} channels, the DEM contains:
\begin{itemize}
    \item a set of \emph{syndrome detectors} $\mathcal{S}$ (standard stabilizer checks),
    \item a set of \emph{herald detectors} $\mathcal{H}$ (one or more detectors per erasure check).
\end{itemize}

For each DEM error $E_j$, we record:
\begin{itemize}
    \item its base probability $q_j$,
    \item the set of detectors it touches,
    \item which heralds $h \in \mathcal{H}$ it is incident on.
\end{itemize}

\subsubsection*{Base and Heralded Weights}

From $q_j$ we define a base log-likelihood weight
\begin{align}
    w^{(0)}_j = \log\!\left(\frac{1 - q_j}{q_j}\right).
\end{align}
When a herald $h$ fires, we model the conditional probability of associated errors as $p_{\mathrm{herald}} = \alpha$ (we use $\alpha = 0.5$), with
\begin{align}
    w^{(\mathrm{herald})} = \log\!\left(\frac{1 - \alpha}{\alpha}\right).
\end{align}
For each pair $(h,j)$ we define a weight shift
\begin{align}
    \Delta w_{h,j} =
    \begin{cases}
        w^{(\mathrm{herald})} - w^{(0)}_j, & \text{if error } E_j \text{ touches herald } h, \\[4pt]
        0,                                 & \text{otherwise}.
    \end{cases}
\end{align}
These $\Delta w_{h,j}$ values are precomputed and stored as a matrix $\Delta W$.

\subsubsection*{Per-Shot Edge Reweighting}

Each noisy shot yields a bitstring $z\in\{0,1\}^m$ over all detectors. We extract
\begin{align}
    s & = z|_{\mathcal{S}} \quad\text{(syndrome detectors)}, \\
    h & = z|_{\mathcal{H}} \quad\text{(herald detectors)}.
\end{align}
Treating $h$ as a binary row vector indexed by $\mathcal{H}$, the per-shot edge weights are
\begin{align}
    w^{(\mathrm{shot})}_j
     & = w^{(0)}_j + \sum_{h' \in \mathcal{H}} h_{h'} \, \Delta w_{h',j}, \\
    \mathbf{w}^{(\mathrm{shot})}
     & = \mathbf{w}^{(0)} + h \, \Delta W .
\end{align}
We pass $\mathbf{w}^{(\mathrm{shot})}$ and the syndrome $s$ to PyMatching, which performs a single MWPM decode on the same DEM graph but with this reweighted edge set. The output determines the logical correction applied for that shot.



\section{Appendix: Additional Notes on Leakage}\label{appendix:leakage}
A leakage occurs when a qubit ``leaks'' out of the computational subspace (described by a two-dimensional Hilbert space) into a state that can only be described with a higher-order Hilbert space. If leakage goes undetected, the error compounds over time as it spreads through a multi-qubit interactions. Leakage can be stochastically modeled with a 3-level system (qutrit) with orthonormal basis: $\set{\ket{0}, \ket{1}, \ket{2}}$. Leakage events are assumed to be discrete and occur independently with probability $p_{\text{leak}}$ at each gate operation acting on the qutrit \cite{suchara_leakage_2014}. The leakage error $E_{E_{\uparrow}}$ on the $j$th qutrit in the system can then be understood as:
\begin{align}E_{\text{leakage}}(\rho_j) & = (1-p_{\text{leak}})\rho_j + p_{\text{leak}}\ket{2}\bra{2} & \quad \text{[Leakage error channel \cite{suchara_leakage_2014}]}
\end{align}

Leakage-reduction units (LRUs) were proposed as a way to convert leakage errors into Pauli-type errors, based on a one-bit teleportation protocol that effectively moves the logical state from the physical qubit in the leaked state to a freshly-prepared physical qubit \cite{suchara_leakage_2014}.

All species of qubit experience leakage errors, but it's important to note the underlying \emph{physical} processes look and behave very differently despite sharing a common mathematical description.


Transmon leakage. Transmon single and two qubit gates rely on coherent microwave driving to transition between computational basis states. Two qubit gates such as the control Z and control X gates are the primary source of leakage in transmon qubits because of their temporary usage of states outside of the computational basis to induce phase and bit flips in the target qubit. For example, when applying a control Z gate on transmon hardware to the state {$\ket{11}$}, temporarily force both excitons onto one qubit, pushing it into the second excited state, {$\ket{2}$}, and letting the other qubit fall into the ground state, {$\ket{0}$}, before allowing the system to relax back into {$\ket{11}$} with the intended phase shift applied. However, there is a nonzero chance that the system does not relax properly, and leaves one of our qubits in the {$\ket{2}$} state, causing a leakage error in our system.

Neutral atom / Rydberg leakage. Neutral atom quantum computers exploit the large effective atomic radius of Rydberg states to perform two qubit gates. When an electron is excited to a Rydberg state, the separation between the electron and the now ionized nucleus creates an electric dipole field, which shifts excitation energy of the Rydberg state, an effect called Rydberg blockade. Following the protocol from Jaksch et. al, to perform a control Z gate, apply a {$\pi$} pulse to excite the control qubit into a Rydberg state, apply a 2{$\pi$} pulse to the target qubit, and then apply a {$\pi$} pulse to deexcite the control qubit \cite{Jaksch_Fast_Quantum_gates_2000}. If both qubits are in the {$\ket{0}$} then the state will remain unchanged, but if exactly one qubit is in the {$\ket{1}$} state then a rotation by 2{$\pi$} and thus a phase shift of -1, will be applied. If both qubits are in the {$\ket{11}$} state then after the first pulse, the Rydberg blockade will prevent the second excitation and a phase of -1 will be applied. Finally apply a Pauli Z gate to both qubits to shift the states -{$\ket{01}$ and -{$\ket{10}$ to {$\ket{01}$ and {$\ket{10}$. Occasionally when applying this protocol, the Rydberg state will not decay back to the {$\ket{1}$} state, and will instead decay to an orbital state outside of our computational basis, causing a leakage error. \cite{morgado_quantum_2021}

Leakage-detection units (LDUs) were developed to address leakage errors in superconducting qubits, by periodically coupling a data qubit to an ancilla that flags when the data qubit leaves the computational subspace. The flagged data qubit can be reset/replaced during subsequent error-correction cycles, effectively treating the flagged qubit as an erasure error.

Neutral atoms / Rydberg arrays, each atom is arranged into a known position using optical tweezers. Although the lattice/trap is situated inside a vacuum chamber, some nonzero amount of background gas collisions or thermal energy transfer from the environment can eject an atom from its lattice site

\subsection{Appendix: Erasure Tolerance and Enhancements}

If left uncorrected, erasure errors pose a existential threat to encoded logical qubits that utilize the surface code encoding schema. While it is possible to compensate to some degree for erasure errors via the introduction of superstabilizers, the accumulation of erasures will eventually render your state unreconstructable if left unchecked. Kobayashi et al showed that a probability of erasure as low as 0.1\% can lead to logical failure rates increasing with code distance in regimes where the Pauli error rate is less than or on the order of 0.1\%. This suggests that to build a functional quantum computer, using the standard surface code encoding and the minimum weight perfect matching algorithm, one would need $p_{erase} << p_{pauli}$.
\cite{kobayashi_erasure-tolerance_2025}

\begin{align}
    E_d & \propto \dfrac{p}{p_{thr}}^{(d+1)/2} & \quad \text{[Logical error rate]}
\end{align}

Therefore when $p << p_{thr}$, the logical error rate is supressed exponentially with code distance. The exponential supression factor $\Lambda$ is approximately the linear relation between $p_{thr}$ and $p$: \cite{acharya_quantum_2025}.

\begin{align}
    \Lambda & = \dfrac{E_d}{E_{d+1}} \approx  \dfrac{p_{thr}}{p} & \quad \text{[Supression factor]}
\end{align}
